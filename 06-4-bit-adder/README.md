# 4-bit Ripple-Carry Adder

This project is a 4-bit binary adder designed and simulated in CircuitVerse.

The circuit adds two 4-bit binary numbers and produces a 4-bit Sum along with a Carry Out.

## 🧠 How It Works

The 4-bit Ripple-Carry Adder is built using **four Full Adders** connected together.

Each Full Adder adds three 1-bit inputs:

- A = First binary bit
- B = Second binary bit
- Cin = Carry coming from the previous stage

It produces:

- Sum = Result bit
- Cout = Carry passed to the next stage

The four Full Adders are connected from the **Least Significant Bit (LSB)** to the **Most Significant Bit (MSB)**.

The carry generated by one Full Adder becomes the carry input of the next Full Adder. This is why it is called a **Ripple-Carry Adder** — the carry "ripples" through the circuit from one stage to the next.
